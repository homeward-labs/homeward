# 家卫 Homeward

> 跑在飞牛 NAS 等家庭服务器上的轻量服务 —— **看清家里每个智能设备在跟谁说话，并能在 30 秒内一键拦下可疑外联**。

**家卫是「设备外联流量治理」工具，不是摄像头、不是安防监控 App。** 我们不拍你、不装你的设备，只在网络层看清并管好"谁在给外面打电话"。

- 中文文档：[docs/README.md](docs/README.md) · 阻断策略：[docs/BLOCKING.md](docs/BLOCKING.md) · 竞品分析：[docs/COMPETITORS.md](docs/COMPETITORS.md)

## 它能做什么

| 维度 | 能力 |
|---|---|
| **看见** | 自动发现家里的智能设备（摄像头/电视/音箱/扫地机/门铃…），画出每个设备连了哪些外部域名与组织；识别突发上传、心跳信标、半夜异动、局域网内跨设备追踪；**把加密 DNS 等看不到的盲区在 UI 上明示**。 |
| **拦下** | 三级阻断：软（DNS 级 NXDOMAIN）/ 中（网段·ASN 级 drop）/ 硬（VLAN 隔离）。阻断前预览后果；**30 分钟内一键撤销，且永远可人工恢复**；撤销后主动核验设备真的恢复。 |
| **读懂** | 中文人话告警（"客厅摄像头半夜向陌生 ASN 连了 73 次"）；判定可解释；AI 辅助默认关闭、需手动触发。 |

**与"只看不拦"类工具的根本区别**：家卫能真的把可疑外联拦下来，并把"拦得住/拦不住、看得到/看不到"都诚实写给你。

---

## 它不做什么（边界）

- 不解密 TLS（纯元数据判断，合法、可落地、低功耗可跑）
- 不做杀毒、不做企业级 DLP
- 不是摄像头/安防监控 App，不采集你的音视频
- 不默认自动阻断，一切以你确认为准

## 快速开始

```bash
# Docker（开发者）
git clone https://github.com/homeward/homeward
cd homeward
docker compose up -d
# 打开 http://localhost:9595
```

**飞牛 OS 一键安装（计划中，尚未发布）**：我们计划让飞牛 OS 用户在应用中心搜索「家卫」，或直接侧载仓库内的 `.fpk` 包（`fnpk/`）。⚠️ 该能力**当前未实现**——`fnpk/` 目前仅含打包配置草稿，尚未提交飞牛审核、也未上架应用中心。在此功能上线前，请先用上面的 Docker 方式部署。

> 单网口 Docker 形态下只能看到 DNS 层面（设备往哪个域名打电话）；要看全量流量，建议部署为旁路由或双网口网桥。详见 [docs/README.md](docs/README.md)。
