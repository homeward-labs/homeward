# 家卫 Homeward — 路线图（公开版）

> 定位：**家庭联网设备隐私守护**（为手机/电脑留口）
> 版本模型（open-core）：社区版 MIT 开源（仅「看见」）／标准版闭源付费（含「拦下」）／专业版规划闭源
> 公开仓库：<https://github.com/homeward-labs/homeward>

---

## 我们怎么看这件事

家卫帮你看清「家里每台联网设备都在跟谁联网」，并提醒你哪些连接可能有隐私风险。
它不拍你、不读你内容、不解密 TLS——只看网络层元数据，在本地记录与分析。

## 版本模型（open-core）

| 版本 | 许可 | 能力 |
| --- | --- | --- |
| **社区版** | MIT 开源 | 记录 + 提醒（「看见」） |
| **标准版** | 闭源付费 | 在提醒基础上「直接拦住」可疑连接（含撤销/回退） |
| **专业版** | 规划中 | 高级治理能力 |

> 接口开放、实现闭源：社区版可复用的抽象契约（如阻断执行器的 `Enforcer` / `RevertContract`）
> 会留在公开仓库；真实阻断实现位于独立私有仓库。

## 技术取向

- **不绑定平台**：家卫是一个可自建的轻量服务，以「接入方式」定义能力。
  Linux / Docker 先跑通；飞牛 / 群晖 / OpenWrt 是可选目标，原生包（`.fpk` 等）仍「计划中」。
- **以 DNS 为主（社区版）**：轻量、低权限、低资源，已能支撑「谁、问了什么域名、问了多少次、什么时间」。
- **深度抓包 / DPI / TLS SNI 归标准版及以上**：吃资源、要权限，作为付费增值。

### 采集分层

| 层级 | 能看到什么 | 归属 |
| --- | --- | --- |
| **Tier 1 · DNS** | 设备问了哪些域名、多少次、什么时间 | 社区版 |
| **Tier 2 · 连接元数据**（conntrack） | 设备↔IP/端口、字节数、连接时长 | 社区版 |
| **Tier 3 · 深度抓包 / DPI** | 包级内容、深度检测 | 标准版 |

路径：**Tier 1（DNS）起步 → Tier 2（conntrack）紧随 → Tier 3（深度抓包/DPI）+ 阻断 归标准版**。

## 社区版 MVP 范围

**三个目标**：看得清（5 分钟看懂家里谁在给外面打电话）、看得懂（中文人话告警、判定可解释）、
守得住边界（诚实标注盲区，阻断明确归属标准版）。

**明确不做（Non-goals）**：

- 真实阻断执行（DNS 黑名单 / nft drop / VLAN 隔离）—— 标准版闭源付费能力
- 深度抓包 / DPI / TLS SNI 检测 —— 归标准版
- 解密 TLS
- 杀毒 / 企业级 DLP
- 摄像头 / 安防监控（采集音视频）
- 默认自动阻断（一切以用户确认为准）

## 路线图（分阶段）

| 阶段 | 主题 | 关键交付 | 状态 |
| --- | --- | --- | --- |
| **Phase 0** | 基础与开源治理 | open-core 版本矩阵、闭源防误传机制、仓库上线、定位拓宽、端口 9595、贡献红线 | ✅ 已完成 |
| **Phase 1** | 社区版 MVP（Linux + DNS） | 采集→分析→展示主线跑通；`v0.1` → `v1.0` | 🟡 进行中（主线已完成，部署与真机打磨收尾） |
| **Phase 2** | 社区版成长期 | Tier 2 接入；国产知识库扩量；AI 辅助（默认关）；飞牛适配；社区共建 | 2027-H1 |
| **Phase 3** | 标准版（闭源付费） | 真实阻断三级执行器 + 撤销契约闭环 + 深度抓包/DPI | 2027-H2 |
| **Phase 4** | 专业版 | 高级治理能力（待定义） | 规划中 |

## 知识库与共建

判断「域名属于哪家公司」依赖特征库。社区版内置基础库，完整数据通过可配置的内容源更新；
**国产智能设备外联归属是当前最大空白，欢迎社区共建（CC BY 4.0 署名）**。
