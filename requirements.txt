# 家卫 Homeward — 社区版 Python 依赖
#
# 社区版 MVP 刻意做到「零第三方依赖」：采集、解析、规则判定全部使用 Python 标准库。
# 这带来三个好处：
#   1. 低配 NAS / 路由器上镜像体积最小、启动最快；
#   2. 供应链攻击面最小 —— 一个隐私工具不该拖进几十个传递依赖；
#   3. 任何一台装了 Python 3.10+ 的 Linux 都能直接跑，不必等镜像构建。
#
# 本文件被 docker/Dockerfile 的 `COPY requirements.txt .` 引用，**请勿删除**。
